A DATA 497 Data Narrative

Priced Out: When a Full-Time Wage No Longer Covers the Rent

Across the U.S., paychecks have grown — but not fast enough to keep up with the cost of a place to live. This is the story of the gap between what people earn and what it costs to keep a roof overhead.

About this project

This project has a simple claim: the cost of living crisis is a result of wages stagnating over time. Across the United States, paychecks have grown, but not fast enough to keep up with the rising cost of everyday life. To support this narrative, we created three visualizations using data from various sources, all showing insight into the current economical situation.
